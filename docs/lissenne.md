# Lissenne

## Language practice grounded in real audio

[Open Lissenne](https://lissenne.com)

Lissenne turns authentic audio into focused dictation and language-practice loops. The product is designed around a simple idea: learners improve faster when listening, typing, feedback, and repetition belong to one calm workflow.

## Core surfaces

| Surface | Purpose |
| --- | --- |
| Dictation player | Listen, type, and receive focused feedback |
| Content library | Find practice by language, level, and topic |
| Flashcards | Revisit vocabulary in context |
| Progress | Make practice and improvement visible |
| Multilingual content | Support several learning languages in one system |

## Engineering shape

The private application combines Django 6, React/TypeScript player bundles, PostgreSQL, Celery, Redis, and Docker. Content tooling handles structured exercises and media; the browser experience keeps the learner focused on the current audio and answer.

## What I focused on

- Turning real media into structured practice
- Building a player that supports multiple practice modes
- Keeping content, feedback, and progress connected
- Balancing a rich learning system with a calm interface

The implementation repository is private; the live product is available at [lissenne.com](https://lissenne.com).
